01 /

任务与建模思路

在生态毒理学与风险评估中，环境化学品的生物富集因子 FBC、生物放大因子 FBM 和生物积累因子 FBA 是重要的预测终点。体内实验耗时长、成本高，相关数据往往具有小样本特征。基于共享参数的迁移学习可利用相关任务中的结构信息，缓解目标任务的数据不足问题（Xiao et al., 2024）。

本案例以正辛醇–水分配系数预测为源任务，利用图神经网络学习分子拓扑结构的通用表征，再将预训练网络参数迁移至 BCF、BMF 与 BAF 目标任务。代码使用 BCF、BMF、BAF 分别对应书稿中的 FBC、FBM、FBA。

STEP 01

源任务预训练

以分子图为输入，学习与正辛醇–水分配性质相关的结构表征。

STEP 02

参数迁移

加载预训练权重，用于初始化目标网络的共享结构层。

STEP 03

目标任务训练

采用冻结共享层或微调参数的策略，学习目标终点的预测关系。

STEP 04

结果评估

在相同数据划分下比较单任务、多任务与迁移学习的预测表现。

04 /

运行导读

学习者可按照数据准备、源任务预训练、目标任务训练和性能评价的顺序开展实践。模型训练可在本地计算机或计算服务器上进行。

1　获取项目与准备数据
git clone https://github.com/baixiaoling77-cloud/TL-MT-Bio.git
cd TL-MT-Bio

也可使用上方“下载完整仓库”。数据准备包括分子结构表示、预测终点整理及训练集、验证集与测试集划分。建模时应保持 CSV 数据、分子图缓存与划分文件之间的一致性。

2　准备环境与预训练权重

运行环境主要包括 PyTorch、DGL、RDKit、NumPy 和 pandas。根据计算设备选择相容的软件版本，并配置 Python 环境与 CUDA 支持。

源任务预训练以 KOW 数据为输入，目标任务训练使用相应生物蓄积性终点数据。迁移学习阶段加载预训练权重，并使权重文件、网络结构与目标任务配置相匹配。

3　按预训练与目标训练顺序运行

完成数据、运行环境和权重配置后，按以下流程示例开展训练。各脚本的任务选择、输入路径及训练参数在 args 中设置。

# 源任务预训练
python RGCNKOW.py

# 单任务基线（其他终点使用对应脚本）
python RGCNBCF.py

# 多任务学习
python MT.py

# 加载相容预训练权重后进行迁移学习
python TLMT.py

代码中的任务选择、学习率、随机种子、设备及输入路径主要在脚本内设置。TLMT.py 采用冻结图网络层的迁移策略，训练目标任务相关参数。学习者可结合实验设计，比较冻结共享层与全网络微调的效果。

4　比较性能与解释结果
  1. 读取 result/ 中对应任务的 CSV，分别分析 training、valid 和 test 分组结果，并以 R² 评价回归模型的预测表现。
  2. 比较同一终点时，保持数据划分、标签处理与评价尺度一致，使用独立测试集评估模型的泛化能力。
  3. 对于多次独立运行的结果，报告均值与标准差，并记录随机种子，以分析模型表现的稳定性。
  4. 结合样本量、任务相关性与模型适用域，讨论不同终点上的迁移效果及其差异。
